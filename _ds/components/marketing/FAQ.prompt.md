Questions as rules, not cards. One open at a time; the first is open on mount so the pattern is legible without a click.

```jsx
<FAQ items={[
  {q:"Do I need an implementation partner?", a:"No. Connect Shopify and import your BOMs yourself."}
]}/>
```

Answers stay under about 60 words. If an answer needs more, it is a docs page, not an FAQ.
