The Manuva signature: the number is the headline. Use for KPIs, empty states, poster stats.

```jsx
<Metric label="Units short" value="1,240" unit="ea" tone="danger" size="lg" />
<Metric value="26" unit="days" size="hero" crop />
```

Rules: one hero numeral per view. Label above, unit beside — never below. `crop` at hero/xl so digits bleed past their box.
