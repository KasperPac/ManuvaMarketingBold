# UI kit — documents

Tier 5 surfaces that leave the building. A4 (794 × 1123 px at 96dpi), print stylesheet included, **monochrome by construction** — these files use no colour at all, so a fax or a mono laser print is the design, not a degradation.

| File | Document |
|---|---|
| `purchase-order.html` | PO-1042 to a supplier — header lockup, 3px rule, mono line items, hero total numeral |
| `packing-slip.html` | PS-8814 to a customer — pick tick boxes, big shipped counts, signature block |

## Rules

- **Status is a word inside a stamp**, not a colour: solid rule = confirmed, dashed = pending/partial.
- **The 3px rule under the header** is the only graphic device. No accent bars, no tinted panels.
- **The total is the one hero numeral** — Archivo expanded 800, tabular, ~30–38px.
- **Identifiers are mono** everywhere: SKUs, bins, dates, references.
- Logo prints at 100% K. Minimum lockup height in print is 8mm.
